# Python-Interview-Programs

This repository contains basic Python programming practice programs created as part of my Python learning and interview preparation.

## Programs Included

1. **Reverse String** – Reverses a given string.
2. **Factorial Number** – Calculates the factorial of a number.
3. **Fibonacci Number** – Generates Fibonacci numbers.
4. **Prime Numbers** – Checks whether a number is prime.
5. **Sum of Digits** – Calculates the sum of digits of a number.

## Files

```text
01_reverse_string.py
02_Factorial_number.py
03_Fibonacci_number.py
04_Prime_Numbers.py
05_Sum_Digits.py
```

## Concepts Practiced

* Variables

* `for` and `while` loops

* String manipulation

## Purpose

The purpose of this repository is to practice fundamental Python programming concepts and prepare for Python coding interviews.

## How to Run

Clone or download this repository and run any Python file:

```bash
python 01_reverse_string.py
```

You can replace the filename with any of the other programs.
